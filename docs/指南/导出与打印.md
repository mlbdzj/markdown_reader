# 导出与打印

md_reader 提供两种把笔记分享出去的方式。

## 导出 HTML

点击工具栏中的 **导出 → 导出为 HTML**，会下载一个独立的 `.html` 文件：

- 页面样式已经内联，不依赖本应用或网络；
- 笔记中的本地图片会被转换为 data URL 一并打包（单张图片上限 8MB）；
- 主题跟随当前界面（浅色 / 深色）。

> 站内 `.md` 链接在导出的 HTML 中仍然是相对链接，若需要一起分享，请把相关文件一并复制。

## 导出 PDF

选择 **导出 → 导出为 PDF（打印）**，应用会打开系统打印窗口：

1. 目标打印机选择 **“另存为 PDF”**；
2. 建议关闭“页眉和页脚”，保留默认边距或选择“无”；
3. 打印样式会自动隐藏侧栏、编辑器和工具栏，只保留文章正文。

## 打印时的排版

| 项目 | 处理方式 |
| --- | --- |
| 字体 | 12pt 正文，固定浅色打印配色 |
| 代码块 / 表格 | 避免跨页截断 |
| 链接 | 保留链接颜色并加下划线 |
| 图片 | 自适应页面宽度 |
