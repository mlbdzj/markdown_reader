# 欢迎使用 md_reader

**md_reader** 是一个运行在 Windows 桌面的本地 Markdown 与文本读写工具：左侧编辑，右侧实时预览，所有文件都保存在本地，不依赖云服务。

![md_reader 的工作方式](assets/markdown-demo.svg)

## 这里可以做什么

- **读写 Markdown**：编辑与预览左右分栏，拖动中间分隔条可以调整比例。
- **支持其他文本**：也可以打开或新建 `.txt`、`.json`、`.yaml`、`.log` 等文本文件，预览会按纯文本或语法高亮展示。
- **管理笔记**：在侧栏新建文件、新建文件夹、重命名、删除，目录树会即时刷新；也可以直接在工作区或左侧文件列表右键新建。
- **全文搜索**：按 `Ctrl + K` 聚焦搜索框，输入关键词即可看到匹配的文件与行号。
- **文档内查找**：按 `Ctrl + F` 在当前文档中查找，`Enter` / `Shift + Enter` 跳到下一处或上一处，`Esc` 关闭。
- **拖拽打开**：把 Markdown 或文本文件拖进窗口即可直接打开；笔记目录内的文件会显示在侧栏，目录外的文件按原路径读写。
- **在线阅读体验**：浅色 / 深色主题、字号、行高、字体和阅读宽度都可以在设置中调整。
- **导出分享**：一键导出为独立 HTML（图片会内联），或通过应用内打印导出 PDF。
- **自动保存**：默认开启，停止输入约 1 秒后自动写回文件，也可以按 `Ctrl + S` 手动保存。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + S` | 保存当前文件 |
| `Ctrl + K` | 聚焦搜索框 |
| `Ctrl + F` | 在当前文档中查找 |
| `Ctrl + B` | 展开 / 收起侧栏 |
| `Ctrl + E` | 编辑 / 分栏 / 预览 三种视图循环切换 |
