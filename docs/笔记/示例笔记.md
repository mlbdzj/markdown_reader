# 示例笔记：如何整理一篇长文

这是一篇示例笔记，可以直接改写或删除。

## 写作前

1. 明确读者是谁，他们想解决什么问题；
2. 列出三到五个关键结论；
3. 为每个结论准备例子或数据。

## 结构模板

```
# 标题
## 背景 / 问题
## 核心结论
## 具体做法
## 常见问题
## 参考
```

## 写作中的小技巧

- 一段只讲一件事；
- 先写内容，再统一调整格式；
- 重要结论放在段首，避免读者寻找；
- 用表格对比多个方案，用列表罗列步骤。

## 校对清单

- [ ] 标题是否准确表达结论
- [ ] 术语是否前后一致
- [ ] 链接和图片是否有效
- [ ] 代码示例是否可运行
- [ ] 是否有可以删掉的内容

> 写完不等于完成，朗读一遍往往能发现最多问题。
